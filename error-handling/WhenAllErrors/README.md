# WhenAllErrors

Учебный проект по обработке исключений в параллельных асинхронных задачах.

## Что делает
Параллельно запускает несколько HTTP-запросов через `Task.WhenAll`, обрабатывает случай когда часть задач падает с ошибкой, выводит результаты по каждой задаче.

## Что отрабатывалось
- `Task.WhenAll` с массивом задач
- Поведение WhenAll при исключениях: ждёт все задачи, выбрасывает только одно исключение в catch
- Обход массива задач после WhenAll для разбора ошибок по каждой
- Свойства Task: `IsFaulted`, `Result`, `Exception`
- `task.Exception?.InnerException?.Message` — null-conditional оператор для безопасного доступа к вложенным полям
- Разница между AggregateException и реальной ошибкой внутри
