# Repeat 1 — error-handling

Повторение темы обработки ошибок в async-коде. Написано с нуля без подглядывания в исходный код проектов AsyncTry и WhenAllErrors.

## Что делает
Параллельно запускает 4 запроса к httpbin.org с разной задержкой ответа (3, 5, 10, 4 секунды) при таймауте HttpClient в 5 секунд. Демонстрирует поведение Task.WhenAll при смешанных результатах — успех, отмена по таймауту.

## Что закрепляется
- Task.WhenAll с массивом задач разной длительности
- Три состояния Task: IsCompletedSuccessfully, IsFaulted, IsCanceled
- Правило: проверять успех первым, безопасный доступ к Result
- TaskCanceledException — отмена при таймауте (НЕ HttpRequestException)
- Минимальный catch + детальный разбор ошибок в цикле по задачам
