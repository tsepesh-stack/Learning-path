# Task-Manager
Консольное приложение для управления задачами на C#
## Возможности

- Добавление задач с описанием, статусом и приоритетом
- Удаление задач по ID или названию
- Просмотр всех задач с фильтрацией по статусу и приоритету
- Изменение любых параметров задачи
- Архивирование выполненных задач в отдельный файл
- Автоматическое сохранение данных в JSON

## Технологии

- C# .NET 10
- LINQ
- System.Text.Json
- File I/O

## Структура

- `Program.cs` — точка входа и вся логика приложения
- `Task.cs` — класс задачи и enum'ы Status и Priority
- `tasks.json` — активные задачи
- `tasksdone.json` — архив выполненных задач

## Как запустить

```bash
dotnet run
```

## Планы развития

- Telegram-бот для удалённого управления задачами
- Веб-версия на ASP.NET Core
