# Learning-path
Обучение и углубление знаний программирования.

## Структура

### async-await/
Освоение асинхронного программирования.
- `coingecko-parallel/` — параллельные запросы к CoinGecko API через Task.WhenAll

### error-handling/
Обработка ошибок в async-коде.
- `AsyncTry/` — try/catch вокруг await, ловля HttpRequestException и TaskCanceledException
- `WhenAllErrors/` — обработка исключений в Task.WhenAll, разбор ошибок через IsFaulted/Exception

## Стек
.NET 10, C#
