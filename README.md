# LayoutSwitcher (LS2)

Утилита на C# для конвертации текста между английской и русской раскладками клавиатуры.

## Проблема

У меня часто бывает что залипает клавиатура или забыл поменять раскладку. Например хотел написать `привет`, а получилось `ghbdtn`. Ls2 решает эту проблему — переводит уже набранный текст на правильную раскладку.

## Возможности

- Конвертация текста с английской раскладки на русскую и обратно
- Работа через буфер обмена — текст берётся из буфера и кладётся обратно
- Автоматическое определение направления перевода (eng→rus или rus→eng)
- Сохранение пробелов, цифр и знаков препинания

## Технологии

- C# .NET 10
- System.Windows.Forms (для работы с буфером обмена)
- Dictionary, LINQ

## Как использовать

1. Скопируй текст в буфер обмена (Ctrl+C)
2. Запусти программу:
```bash
dotnet run
```
3. Программа покажет результат и положит его в буфер
4. Вставь куда угодно (Ctrl+V)

## Структура

- `Program.cs` — основная логика программы
- `LS2.csproj` — конфигурация проекта (TargetFramework: net10.0-windows)

- Автоматическое нажатие Ctrl+C и Ctrl+V
